# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-19

### Added

- Fail-closed runtime configuration with Cloudflare Access and trusted-proxy authentication modes.
- Identity-bound CSRF and download tokens, authenticated health reporting, and cursor-paginated job history.
- Native ComfyUI model and user-directory discovery with explicit environment overrides.
- Resumable, capacity-aware downloads from canonical Hugging Face and Civitai sources.
- Retry phases, cancellation checkpoints, safe partial-file cleanup, and retained job history.
- SHA-256 and Safetensors validation followed by descriptor-bound, no-replace publication.
- English Server Model Downloader sidebar with explicit scanning and stale-request cancellation.
- Comfy Registry metadata, CI, CodeQL, release automation, and public project documentation.
